# Warp Type

A browser tool for making warped, distorted, extruded type. Everything runs in the page: type your lines, load your own fonts, shape the distortion, and download the result as SVG or PNG.

Live tool: https://YOUR-USERNAME.github.io/REPO-NAME/

## Use it
Open `index.html` in a browser, or visit the live link above. No install or build step.

## Notes
- Fonts load from your computer (.ttf / .otf / .woff). WOFF2 is not supported.
- The default font (Anton) and the font library load from public CDNs, so you need an internet connection.
- Make sure you have the licence to use any font you upload.
